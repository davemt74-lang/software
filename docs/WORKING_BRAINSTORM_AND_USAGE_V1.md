# Working, opportunities and usage

The orb's work dot is independent of its listening, speaking and Chat state.
It follows actual unexpired workflow leases and clears when work ends, pauses,
loses its lease or leaves the current owner/Agent scope. Brainstorm assessments
appear as an Opportunity Agent in the existing specialist rail.

The existing Initiative planner revisits current sources on its existing
five-minute cadence. A time slot applies only to assessment deduplication;
preparation still deduplicates by policy, tool and exact source revisions.
Ideas are private assessment results, with separate considered, queued and
existing-assignment states. Reading Top of Mind never schedules work. The
entire original evidence snapshot and current tool permissions are checked
again before displaying an idea. An idea never grants approval for an action.

Recent owner Chat purposes, private Canvas metadata and owner song history
join existing calendar, task, reminder, Mission, YouTube and permitted sensory
sources. Guest/shared Chat turns and Canvas code/app data are excluded from
these metadata readers. Existing Knowledge and sensory consent still apply.

The sidebar shows coding model and tokens, with runtime diagnostics collapsed.
The composer no longer has duplicate Top of Mind and popup Chat launchers;
the orb opens Top of Mind. Off-page Chat uses a bounded light composer.

AI Usage defaults to provider calls, supports consistent UTC period filters,
and pages history in groups of 25. Recorded subscription debits missing an
execution row are recovered in a read-only projection with exact deduplication.
Provider observations and subscription debits remain separate, including for
Admin accounts. Local tools do not claim cloud token charges.

Dollar amounts are estimates using configured provider/model rates, not
provider invoices. Missing rates show Unpriced; absent provider usage remains
unknown. Earlier Admin calls with neither a debit nor an execution record
cannot be reconstructed. No token counts or costs are guessed from message
length. CSV uses the same canonical report as the page.

Deploy on the current main baseline and run Database Upgrade. Existing saved
Initiative settings, selected coding model and Auto Build controls continue
to govern work. No new standalone worker, queue or billing store is required.
