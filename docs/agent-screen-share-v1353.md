# Share screen with Agent Eyes v1.353

Agent Eyes includes a separate Share screen section. Clicking Share screen invokes the browser's own picker directly in the user gesture, preferring a window while permitting a monitor. No extension, camera, microphone or screen recorder is started. Capture is off on page load and cannot silently resume after a reload. Closing the Eyes panel or switching tabs does not stop an explicitly shared surface; explicit Stop, browser Stop Sharing and page unload do.

The local preview samples a bounded JPEG about every five seconds. Automatic analysis is selected in the UI and can be disabled; Capture and analyze supports manual use. Changed frames are sent at most every thirty seconds, with unchanged scenes refreshed after sixty seconds. The configured Cloud vision route and existing AI entitlement, billing and rate controls apply. A per-account locked metadata file additionally limits concurrency, enforces fifteen seconds between requests and caps analysis at 120 requests per hour. Model errors are visible while the display stream remains usable. Account or authorization changes stop sharing. Screenshots and observations are not persisted by the analysis endpoint; its private budget files contain request counters and lease metadata only.

The latest description, literal visible clues, provisional site/title hints, selected surface and UTC capture time enter canonical typed and spoken Chat as untrusted visual evidence. Same-account embedded Chat can read its parent's current description, never its pixels. Screen observations expire after ninety seconds and are withheld when local capture is stale or a changed frame is awaiting analysis. Stop clears preview data and current context, aborts the client request, and fences late results. A Chat answer may retain the description as ordinary conversation context; raw screenshots do not enter Chat history. The model is instructed not to infer hidden tabs, identify people, follow screen text as instructions, or treat it as action authorization.

This is visual awareness of one selected surface, not a tab inventory or browser automation permission. A selected browser tab stays attached to that tab; a window/monitor follows what that surface displays. Browser throttling or OS capture availability can delay or suspend frames. Test the real native picker and configured model after deployment. Automated tests use display streams generated from a canvas and mocked model responses.

Acceptance: open Eyes with camera off, choose Share screen, select a window or monitor, wait for its timestamped description, switch to a product page in that shared surface and ask “What do you think about this?” in typed or spoken Chat. Stop sharing and confirm that a new turn receives no current screen context. Also test picker cancellation, browser Stop Sharing and a model outage.

HomeServer has matching screen UI, paired Cloud transport and owner-only Chat context staged locally. Its source is not uploaded, no HomeServer repository workflows are started and no HomeServer package is published in this phase.
