# Conversational request routing

A singular, incomplete reminder setup request such as “Can you set a reminder?” now reaches the reminder service instead of an access inventory. The service asks what and when, saves the pending clarification in the existing owner/thread scope, and creates no reminder until the user supplies a complete schedule. General ability questions such as “Can you create reminders?” retain capability inspection. A specific tools/list discovery answer offers currently ready lists in ordinary language; execution receipts remain authoritative metadata.

Transcript selection and the last transcript receipt are reference context. They do not make unrelated reminder, calendar or greeting turns into transcript requests. The transcript relevance gate requires a transcript mention or a relevant reference/follow-up; the interpreter is also instructed to return none for unrelated domains. The bare reminder setup request explicitly passes through. Ordinal answers after a transcript list or clarification use those preceding choices, even when no recording has been selected yet. This is shared by typed, streaming voice and legacy Chat.

Transcript plans accept a validated YYYY-MM-DD recording date for list/read/saved-analysis/saved-research reads. The shared surface sanitizer preserves validated client timezones, with the account calendar timezone as fallback. The server filters actual recording timestamps between local-midnight boundaries in the supplied timezone, including DST, before pagination. This reaches older recordings beyond the recent catalog supplied to the model. A unique authorized match can be read; multiple matches require a user selection, and no matches are reported distinctly. Date filters never authorize writes or run new analysis/research. Existing owner/Agent permissions and live account checks remain in force. Invalid interpretation gets one bounded repair with structured error context, followed by a usable clarification without execution.

Validation includes actual typed/voice/stream/legacy endpoint interleaving of list discovery, incomplete reminder setup, dated transcript retrieval and later reminder reads. Domain tests cover local midnight, a 25-hour DST day, older-than-catalog dates, ambiguous matches, foreign-record exclusion, missing matches and invalid calendar dates. Fixture models provide controlled plans; these checks certify routing and execution, not the language model’s interpretation accuracy for every phrasing. No migration is needed.
