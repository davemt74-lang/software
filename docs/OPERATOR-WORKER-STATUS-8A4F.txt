# Operator 8A.4F — private worker reporting status

Depends on #857. The existing private Operator Specialist Chat/Top-of-Mind path reads the canonical paired grant, current account/pairing and signed worker registry in one owner-scoped statement, with no credentials/ciphertext returned. Disabled deployments keep the old manual-phone contract. State distinguishes absent grant, revocation, changed pairing, awaiting registration, last verified report, stale report, retirement and unavailable data. A report is fresh for at most 25 seconds after the last signed receipt, not for the whole 90-second registration lease. No call readiness, provider certification or execution authority is inferred. The current browser call state retains its independent meaning; the worker text is additional historical evidence. The Operator Brain shows a read-only status section with last verified time and autonomous-calling-off notice, using the existing authenticated activity feed and refresh lifecycle. No new endpoint, browser polling timer, manual call control, claim, model or carrier dispatch. Tests extend the existing SQLite/MySQL authority fixture and mounted Operator Brain browser journey. Live end-to-end acceptance remains independent.
