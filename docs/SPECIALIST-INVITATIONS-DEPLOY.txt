VP3 — Gmail and Media invitations grounded in current private sources

DEPLOYMENT

Extract the complete verified Cloud ZIP over the existing installation, run
Database Upgrade for current main and refresh. This feature adds no tables or
new provider credentials. Existing casual check-in and Media preferences,
permissions, pacing, quiet-chat rules and pending-offer checks still apply.

GMAIL

When a check-in can use saved email work, it lists up to three reviewable drafts
from the newest fifty pending rows for the selected private Agent. High priority
and saved reply deadlines come first; relevant current analysis can break ties
before recency. Each item shows its subject, recipient and useful source reason.

The native draft review helpers exclude sent, discarded, answered, automatic,
expired, stale, incomplete writing, corrupt and changed-grant proposals. An
unavailable pending queue does not turn into a claim that no drafts exist. The
existing generic new-email question remains only for a verified empty queue.
One-time Gmail and Media capability examples yield to meaningful existing work.

Reply yes to see exact review buttons. With multiple drafts, no arbitrary draft
is chosen. Say first, second or third to select the corresponding offered item.
The existing composer opens in the draft's original authorized conversation.
Its send, attachment, follow-up and writing-preference approvals remain separate.
An invitation, response or review does not send mail or rewrite a draft.

The offer pins every displayed draft's original conversation and native edit
revision. Newer drafts cannot replace the offered list. Editing, discarding,
answering, revoked source access or a changed mailbox makes the old choice stale.
Replay recovery also rechecks the source before returning saved review actions.

MEDIA

Native music invitations name a real current catalog choice and known artist or
genre. Saved YouTube videos or search topics use the existing history reader,
consent and source expiry. Combined invitations present the named choices. If
there is no usable saved YouTube choice, the invitation offers the named native
track alongside finding something new on YouTube; it does not invent a video.
Bare assent to two possible paths asks which path. Exact music or video replies
reuse the existing native Player or saved YouTube action.

No invitation starts audio, creates a listen, runs a provider search or grants
permission. Expired provider results retain only an allowed original search
topic, and a further owner action uses the existing search workflow. This
feature adds no competing player, preferences system or listening history store.

CURIOSITY AND BRAINSTORMING

Only the existing receipt-verified, currently source-authorized native reports
can contribute. Two meaningful topic words must overlap a candidate before an
analysis may affect its ranking or appear as a possible connection. The wording
explicitly labels the relationship as possible, rather than a verified fact or
an inferred preference. The report key is part of the exact offer revision;
withdrawn or changed analysis invalidates that context. No additional model
request is made to create an invitation. Mail bodies and send approvals are not
copied into the invitation or a new analysis store.
