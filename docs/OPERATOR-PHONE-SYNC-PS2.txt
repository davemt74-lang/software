# Phone Sync PS2 — private Chat Canvas setup and test calls

The owner can type “Call me”, “Connect my phone”, “Sync my phone”, or “Test my phone” in eligible private Chat, or use Phone > My phone in Chat. Exact local commands open one private ephemeral Chat Canvas card; they do not send the number or settings to the language model or add a raw phone number to the stored conversation. Account and Chat use the same owner settings and revision, and number changes clear previous outreach requests. Separate update and hello toggles remain requested preferences, not autonomous execution. Existing Account call-window and limit settings are preserved by Chat toggles.

Test Call requires a trusted explicit user click and personal-number/charge acknowledgement. It uses the currently assigned authorized browser Phone line, existing microphone lease, one-use canonical call intent, exact saved phone revision, no recording and no AI captions. No SMS, Verify, challenge code, or mandatory verification. Server never accepts a client-selected destination in the test action, caps call duration to 60 seconds, requires at least 120 seconds between test preparations and at most three per rolling day, and rechecks number revision at the signed carrier voice callback. A canonical test call appears in the normal phone ledger and Chat. “I received it” stores a separate user acknowledgement after signed answered/completed evidence, not proof of identity or autonomous authorization. Number changes invalidate the last-test projection. No automatic dial, auto-retry, native Agent speech, or production test call performed in CI. Browser must be open for this reachability test. Twilio voice charges may apply to user-triggered test calls.

The two additive phone_browser_calls_v1 fields are installed by the existing Phone workspace schema upgrade. Existing manual Phone and recording paths are unchanged apart from required migration readiness. No new public endpoint or live verification service. Future connected-phone permission and native autonomous calling builds are separate.
