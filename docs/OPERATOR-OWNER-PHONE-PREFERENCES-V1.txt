# Operator owner-directed calls — private Account preferences (foundation)

Adds Account > Phone & Agent Calls, separate from the Agent's assigned Twilio line and CRM contacts. Store the owner-entered international callback number and two independent default-off preferences: Chat Canvas updates (important/actionable by default, optional eligible grouped updates) and friendly hello/check-in calls. A local time zone, same-day allowed window, maximum calls per day (1–3), minimum gap (at least 2 hours), and maximum duration (1–5 minutes) are persisted. The full number is available only to the authenticated owner Account settings flow, never a public Profile field, CRM import, Agent prompt, shared Chat or activity response. The owner session, current password fingerprint, active account, account permission, nonparticipant context, CSRF and optimistic revision are checked. Number change or removal resets both requests; account deletion cascades. Setup/upgrade install the dedicated table; read does not install or create a row.

The preferences express requested future outreach only. No phone verification, dial grant, carrier request, billing, scheduler, recording/transcription or autonomous dispatch is introduced. The private settings view always returns verified=false and execution_enabled=false. Future work: prove possession with an independently approved verification challenge, bind verified number/revision and owner policy to a single authorized assigned line, choose eligible verified Chat findings and a private owner conversation, batch updates, enforce quiet hours and shared daily/min-gap/spend counters, avoid duplicate calls and missed-call retry storms, identify the Agent and allow immediate stop, record/transcribe only with applicable disclosure and consent. A friendly check-in needs its own affirmative opt-in and the same limits. Do not call unverified numbers or infer consent from a saved phone number.

Run the dedicated SQLite and MySQL fixture and Account contract checks in Section 14 CI. Browser and deployed verification/calling acceptance remain separate.
