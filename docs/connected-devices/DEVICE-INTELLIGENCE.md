# Future intelligence extensions
Apps: native, declarative dynamic, remote-rendered; reuse Apps/plugin lifecycle, versioned packages, compatibility and release-bound approvals. Initial UI vocabulary cards/lists/checklists/text/actions/audio/haptics with fallback per capability. No arbitrary downloaded executable code initially.
Skills: bounded reusable workflows combining approved tools; discovery by capabilities, trigger, input/output schema, permissions, version, timeout and receipts. Coding Specialist can propose/test custom skills.
Memory: scoped references to canonical Knowledge/Brain, device preferences, temporary context, task continuity; review/correct/delete/expire, no private transfer on reassignment.
Tasks: canonical task reference, assignment, acknowledgment, progress, evidence, verification, expiry and reassignment within original scope. Recurring tasks retain objectives and run history.
Missions: extend existing mission engine; dependency graph, device/specialist/user assignments, budgets, evidence, corrective actions and outcome learning. Example restaurant inspection: glasses observations, watch checklist, sensors readings, HomeServer analysis, desktop report.
Workspaces: devices, apps, skills, scoped knowledge, tasks, missions, specialists/models, schedules, policies and communication. Personal/home/restaurant/studio templates; switching never grants new access.
Collaboration: shared session ID, participants, objective, authorized routes, single response authority; handoff watch→phone/desktop, local gateway preferred; discovery via mDNS/BLE is not authorization.
Autonomy: passive, interactive, routine-enabled, context-aware, delegated, coordinated. Execution envelope objective/duration/skills/devices/budget/privacy/stop/evidence. Never override mandatory approval.
Personas: same Agent, configurable name/voice/style/length/orb/greeting/proactivity/quiet hours/language. Defaults→workspace→device→app/mission→temporary instruction, security above all.
Ambient: extend existing v0.80/v0.90; bounded observations with source/time/confidence/expiry, deterministic filtering, specialist assessment, Top of Mind, useful announcements, verified follow-through. No unrestricted surveillance or automatic physical activation.
Resources: battery, bandwidth, CPU/RAM/storage, model availability/cost; profiles performance/balanced/battery/local/economy; per-device/workspace/mission attribution, privacy before cost, deterministic routine events rather than LLM calls.
Devices Specialist: discover useful work, assess, coordinate, report to Top of Mind, announce high-priority findings in Main Chat, verify, reassess; reasonable reminders and dedup. Own model/settings/Brain/History/Reports via existing specialist infrastructure.
Experience Builder: natural-language configuration of apps/skills/persona/permissions for review. Marketplace later: apps, skills, mission/workspace templates, drivers, themes, certified firmware; audit existing commerce first.
