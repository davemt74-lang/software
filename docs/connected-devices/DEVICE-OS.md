# Runtime and hardware
Device OS is a portable runtime, not new kernel. Modules: boot/recovery, identity, connection, protocol, policy, app/UI/skill runtime, sessions, context, resources, offline manager, signed updates, diagnostics, HAL. HAL interfaces display/touch/buttons/audio/camera/motion/location/sensors/storage/network/power/haptics/firmware/diagnostics; define async cancellation, ownership, errors and limits. Targets ESP-IDF/FreeRTOS, Linux/Raspberry Pi, Windows, browser/mobile and virtual; capability-dependent, not certified. Preserve existing vp3-hw-v1 serial adapter.
Reference watch: Waveshare ESP32-S3 2.06 AMOLED, proposed ESP-IDF/LVGL; verify board revision, display/audio drivers, memory and power physically. v0.1 pairing/Wi-Fi/Orb/text announcements/touch/ack/battery/basic launcher; v0.2 push-to-talk and spoken responses; later tasks, Top of Mind, dynamic apps, handoff; wake word/continuous voice experimental.
Device Studio: Coding Specialist workspace for datasheets, board profiles, drivers, firmware/apps, isolated compilation, simulator, diagnostics, artifacts/checksums, authorized USB/OTA and physical certification. Prefer declarative app changes over firmware flash. Release rings stable/beta/dev and pilot/staged/broad; signed packages, rollback and recovery. Certification tiers Core, Interactive, Voice, Vision, Automation, Intelligence, Gateway; qualify independently. Source, simulator, platform and physical evidence distinct.
Digital twins: desired/reported/verified state, freshness and revision, offline configuration pending, no false success. Simulator exercises actual API, multiple devices, failure/reconnect, expiry/revocation, duplicate events, permissions and account isolation.
