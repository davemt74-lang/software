# Hosting transition
Owner plans VPS instead of shared hosting. CD1 works on existing HTTPS/PHP/database before migration. Retain PHP/MySQL and canonical job ledger. Proposed Nginx TLS reverse proxy, supervised existing CLI workers, independent Python/FastAPI device gateway, MQTT 5/Mosquitto for events, WebSocket for sessions, HTTPS for pairing/files, existing LiveKit for compatible media; Redis optional cache/event delivery, never competing job authority. HomeServer initiates outbound authenticated connection; no home router inbound ports required. Local-only and authorized hybrid fallback distinct.
Migration checklist: inventory PHP extensions/database versions, cron/worker invocation, domain/TLS, OAuth/webhook callbacks, private config/secrets, uploads, recordings, storage permissions; backup and restore rehearsal; staging; maintenance/cutover/rollback; health and queue monitoring; isolate broker/admin ports; service restart and lease recovery; verify phone, Agent, HomeServer and media. Existing ZIP excludes private data/config and tools; package administrative service tooling separately. Proposed sizing 8 vCPU/16GB/200GB NVMe Ubuntu LTS is unbenchmarked, adjust for media and workload. VPS provider/config not inspected.
