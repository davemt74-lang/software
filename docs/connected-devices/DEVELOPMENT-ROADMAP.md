# Roadmap
Canonical phase order: CD0 discovery; CD1 foundation (A–L in handoff); CD2 persistent VPS connectivity and gateway; CD3 HomeServer network gateway and cross-device sessions; CD4 portable SDK/HAL and laboratory expansion; CD5 physical watch and voice; CD6 Devices Specialist, personas, ambient/resources; CD7 apps/skills/memory; CD8 tasks/missions/workspaces/collaboration; CD9 bounded autonomy and optimization; CD10 Device Studio, firmware certification, developer ecosystem/marketplace. Earlier chat roadmaps used different numbering; this document supersedes them. CD1 includes minimal adapters/twin/simulator/announcement/dashboard, not full later services. Dependencies: virtual end-to-end before hardware; gateway before remote persistent transport; physical tests before certification. VPS migration can proceed independently. Proposed SDK repo not created; decide canonical contract location before implementation, use one source and validated fixtures across repos.
