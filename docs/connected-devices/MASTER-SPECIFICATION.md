# Master specification
VP3 Cloud (existing PHP application), Otro HomeServer (Windows installer/local services), Connected Devices SDK (portable protocol libraries), Device OS (runtime atop existing OS, not a kernel), Device Studio (Coding Specialist workspace) form one ecosystem. First physical target: Waveshare ESP32-S3 2.06-inch AMOLED watch, exact board revision and peripherals unverified. First engineering target: virtual watch pairing, capability discovery, authenticated presence, real Main Agent announcement, acknowledgment in canonical Chat, revocation.
## Boundaries
One Main Agent, canonical conversations, Knowledge, Tasks, Missions, job ledger, approvals and Top of Mind. Device services coordinate hardware, not a second brain. Cloud owns cloud account and native records; HomeServer owns native local records and governed physical actions; mirrors never execute independently. Local-only processing must never silently fall back to cloud. Device identity is independent of installation, credential, user assignment, Agent, network address and connection. Device groups/workspaces scope data, apps and objectives; membership never grants sensor access.
## Product scope
Apps, Skills, Memory, Tasks, Missions, Workspaces, collaboration, autonomy, digital twins, personas, ambient intelligence, resources, development studio, HAL, certification and marketplace are future extensions. See detailed companion documents. Do not build them all in CD1.
## User experience
Connected Devices sidebar, responsive single-page inventory, pairing, capabilities, permissions, state freshness, diagnostics, suspend/revoke. Existing phone tracking stays functional. Main Agent proactively announces meaningful high-priority specialist findings in Chat; eligible device delivery is a projection of the same announcement, with shared acknowledgment and reasonable reminder spacing. No competing speech or duplicate actions.
