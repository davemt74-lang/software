VP3 Cloud — private phone camera preview

Back up the site and database, install this Cloud deploy over the existing VP3
root, and run upgrade.php as an administrator. Use HTTPS on the editor and
phone. Preserve config.php, private/, uploads/ and current environment settings.

From private Agent Chat, type “Request a camera” or “Request a camera from Dave.”
Use the paired phone’s name. If several phones match, reply with its number or
name. A phone can pair using the QR code in Phone Tracking.

On the paired phone, keep the connection page open. Incoming camera requests
appear on both the Connection and Chat tabs. Tap Start Sharing and allow camera
access. On the owner’s computer, open the private preview link in Agent Chat.
Tap Stop Sharing on the phone or in the editor to end sharing.

The holder can also open Chat, tap + beside the message field, and choose
Camera. Preview shows the selected lens locally. Start Sharing makes the
camera available in the owner’s private editor and tracking map. If the phone
is on the map, its marker pulses red while it sends fresh camera frames.
Select that marker to watch. Closing the popup lets the phone keep sharing.

Send messages to the connected agent from the phone’s Chat tab. A reply appears
under the original message. If a reply fails, read the status and tap Retry
reply to keep the original message and its owner announcement. Use Open phone
chat on the owner’s Phone Tracking device card to read the linked conversation.

To let a particular phone save a place, select its card in Phone Tracking and
enable Allow phone to add saved locations. On that phone, open Chat, choose +, then Save
location. Name the spot and tap Save current location. This uses one location
reading. Live location sharing and history can stay off.

Using the phone across different networks
The phone and editor use WebRTC. Direct connections work where the network
allows them. For cellular service or restrictive NAT/firewalls, configure your
STUN/TURN service in the existing private config.php array. For example:

    'phone_camera' => [
        'ice_urls' => [
            'stun:relay.example.com:3478',
            'turn:relay.example.com:3478?transport=udp',
            'turns:relay.example.com:5349?transport=tcp',
        ],
        'turn_shared_secret' => 'your-server-side-coturn-auth-secret',
    ],

Use your own relay hostname, active ports and coturn shared secret. Only the
listed servers are used. VP3 issues temporary credentials for an active
preview. Credentials expire when the pairing expires or four hours after sharing
starts, whichever comes first. The relay secret stays on the server.

Field check
Use Safari on a physical iPhone and open the editor on another device. Check
moving video, holder Stop Sharing, lock/resume, and a fresh request on Wi-Fi
and cellular. If the cellular test fails while Wi-Fi works, verify that the
configured TURN service accepts the temporary credentials.
