# Transcript tools S1: discovery and source reads

Owner Chat now has a dedicated transcript interpreter and read executor shared by canonical typed, legacy and streaming Chat. Open Transcription Intelligence selection is passed as a hint, then revalidated against account ownership and the active Agent's linked conversation scope. Unlinked owner recordings remain selectable; another account, another Agent's linked recordings and discarded sessions do not enter the catalog. Ambiguous reads request a selection.

List, literal search and canonical page reads return speaker/timestamp/segment references, source links, fingerprints and bounded continuations. Transcript content remains data; it cannot create a command or authority. Interpreter errors get one repair attempt; live account and permissions are rechecked before execution. No DDL or Brain copies are needed to read.

Acceptance: production SQLite source reads, scope denial/revocation, page and character continuation, editing fingerprints and execution receipts; production typed/streaming/legacy Longfellow endpoints with selected and forged foreign IDs; actual provider payload builders. Existing Recovery and browser workflows remain merge gates. Live provider/microphone certification remains deployment acceptance.

Later sections add saved analysis/research, analysis execution and reviewed follow-through. Existing Add to Brain currently conflates a one-per-session 2,000-character note with a separate analysis report save; S3 will preserve source-linked highlights and current sharing policy.
